Recursive Binary Tree Generator: A Project for Java Programming II
By: Ace Breaux

Make a pretty tree of your own! Control various inputs of binary trees, such as parent-to-child ratio, color, trunk width and length, angles, color, and recursion depth. Includes visually-appealing hand-drawn assets for the UI. Utilizes Java Swing GUIs to create real-time visual feedback.
Enjoy your aesthetic tree generation.
